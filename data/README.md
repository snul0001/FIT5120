Cleaned datasets used for the project

## Regional Employment Data

Prepared by Cheryl for the Regional Employment Insights feature.

### Main files for development

- `regional_employment_opportunity_clean.csv`
  - Regional employment opportunity data for ICT occupations by SA4 region.
  - Use this file for comparing employment opportunities across regions.

- `regional_employment_demand_clean.csv`
  - Regional employment demand data for ICT Professionals.
  - Use this file for regional employment demand visualisation.

- `regional_ict_occupation_mapping.csv`
  - Maps detailed ICT ANZSCO4 occupations to the ANZSCO2 ICT Professionals group.

### Validation

- `regional_employment_validation_report.txt`
  - Validation results for the regional employment datasets and occupation mapping.
